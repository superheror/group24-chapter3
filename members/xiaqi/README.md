# 我的Git学习笔记
## 第一次Git实验总结
1.git add的作用是：把工作区中修改的文件添加到暂存区，标记这些变更准备下一次提交，此时没有生成快照，只是交给git暂存
2.git commit的作用是：将暂存区中全部已暂存的改动在本地仓库生成一个快照，保存版本历史，附带提交说明，此时仅保存在本地，不会上传到GitHub远程仓库
3.git restore notes.md的作用是：丢弃工作区对notes.md尚未add的修改，将文件内容恢复到暂存区的状态或者是上一次commit的状态，此时撤销了本地没暂时保存的改动
4.commit 与 push的区别是：commit针对的是本地操作，只在本机生成版本记录，不会同步远程；而push是网络上传操作，将本地commit生成的版本快照上传至远程仓库，将本地版本同步到网上
